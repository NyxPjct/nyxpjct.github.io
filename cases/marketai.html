MarketAI

Inteligência de mercado grátis e open source para preço, margem e concorrência.

Ver no GitHub Baixar a versão 1.4.0

Visão geral

O MarketAI ajuda vendedores, pequenas empresas e analistas a decidir se vale a pena vender um produto antes de comprar o estoque. Ele compara marketplaces, converte moedas, simula preços e mostra a margem real. A regra principal do projeto: o app não inventa preços, estoque, vendas ou tendências; quando a evidência é fraca, ele avisa. Sem planos pagos e sem limite de análises.

Destaques

  • Análise de produto com custos, frete, impostos e margem líquida
  • Comparação de marketplaces e sugestão de preço respeitando a margem mínima
  • Catálogo por SKU com busca, filtros e importação em lote por CSV
  • Monitoramento com alertas de variação de preço e de margem
  • Histórico por conta, com análises e alertas separados por usuário
  • Instalador para Windows 10 e 11 em cinco idiomas

segurança e privacidade

Segurança e privacidade

  • Senhas com hash Argon2
  • Tokens JWT de curta duração e refresh tokens rotacionados, guardados como hash
  • Sessão local protegida com Windows DPAPI
  • Dados isolados por conta em todas as consultas
  • UUID aleatório de instalação em vez de fingerprint de hardware
  • HTTPS obrigatório, segredos fora do repositório e instalador publicado com hash SHA-256

Qualidade

A versão 1.4.0 passou por 100 testes do Cloud, 17 testes do Desktop, regressão completa no navegador e validação real de instalação e atualização no Windows. O CI e o build do instalador rodam no GitHub Actions.

MarketAI

Free, open-source market intelligence for pricing, margins and competition.

View on GitHub Download version 1.4.0

Overview

MarketAI helps sellers, small businesses and analysts decide whether a product is worth selling before buying stock. It compares marketplaces, converts currencies, simulates prices and shows the real margin. The project's core rule: the app never fabricates prices, stock, sales or trends; when the evidence is weak, it says so. No paid plans and no analysis limits.

Highlights

  • Product analysis with costs, shipping, taxes and net margin
  • Marketplace comparison and price suggestions that respect the minimum margin
  • SKU catalog with search, filters and bulk CSV import
  • Monitoring with price-movement and margin alerts
  • Per-account history, with analyses and alerts separated by user
  • Windows 10 and 11 installer in five languages

security and privacy

Security and privacy

  • Argon2 password hashing
  • Short-lived JWT access tokens and rotated refresh tokens stored as hashes
  • Local session data protected with Windows DPAPI
  • Data scoped by account in every query
  • Random installation UUID instead of hardware fingerprinting
  • HTTPS required, secrets kept out of the repository and installer published with a SHA-256 hash

Quality

Version 1.4.0 passed 100 Cloud tests, 17 Desktop tests, a full browser regression and real Windows install and upgrade validation. CI and the installer build run on GitHub Actions.
